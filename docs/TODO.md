## 🚀 阶段执行规划（分步演进）

### 阶段一：灾难兜底与信任建立（最快见效，打通完整体验闭环）

目标：让用户敢用（不丢原文件）、愿用（不用每次都下到本地查看）。

- [x] **Task 1.1: 原始文件写前安全备份与防篡改自愈机制**
  - [x] 在文件上传与挂载阶段，自动于 `.sessions/<id>/backups/` 保存不可变原始副本
  - [x] 在 `runPython` 执行前，记录输入文件 SHA-256 指纹并在运行目录建立安全镜像
  - [x] 执行后核验原文件，若被模型违规篡改，自动秒级复原并抛出安全警报触发自愈
- [x] **Task 1.2: 产物 Excel 前 N 行结果预览（弹窗式全宽交互 + 外侧双按钮）**
  - [x] 后端：脚本执行后自动提取产物结构（行数列数、Headers、前 15 行数据），支持 `GET /api/excel/preview` 按需嗅探
  - [x] 前端：右侧沙箱展示「🔍 查看数据与详情」与「📥 直接下载 Excel」双操作按钮
  - [x] 弹出层：创建 `OutputPreviewModal.vue`（90vw 宽屏），集成前 15 行表格、多 Sheet 切换、标杆 Diff 对账与运行日志

### 阶段二：自动化质检护城河（出厂体检与自愈闭环）

目标：机器在交卷给用户之前，自己把全表扫描一遍，拦截丢数据、公式破坏、空值污染。

- [x] **Task 2.1: 实现独立的 `validate_workbook` 检查器**
  - [x] 编写 Python 质检脚本（`validator.py`）与 TypeScript 封装调用（100% 本地纯代码规则引擎）
  - [x] 检查项 1：文件可读性与工作簿完整性（Openpyxl 无损加载，排除伪装成 xlsx 的损坏文件）
  - [x] 检查项 2：维度与行数对账（对比输入表的行数列数，排查意外空表或数据骤降）
  - [x] 检查项 3：单元格异常值扫描（全表排查 `#REF!`, `#DIV/0!`, `#VALUE!` 等公式崩溃符号并定位位置）
  - [x] 检查项 4：字段有效性与公式检查（核查全空废列与动态公式数量）
- [x] **Task 2.2: 接入预检自愈与沙箱执行流**
  - [x] 预检阶段自愈门禁：若产物存在致命硬伤（0行空表、损坏、公式崩溃），自动拦截打回大模型重写修复
  - [x] 前端可视化体检看板：弹窗新增「🩺 出厂质检」专属 Tab，提供 3 类客观状态与事实清单（Checklist）
  - [x] 沙箱主卡片展示健康标签（`🩺 格式健全` / `⚠️ 变动提醒` / `❌ 存在硬伤`）
